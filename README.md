# Predictive-Modelling-Based-on-T-score-and-T-age-Across-Multi-Disease-Antigen-Repertoires
This repository contains the source code files, training data and currently used models for this predictive system

#1. Overview:
The files "three_group_new_training.py", "disease_bin_new_train.py", "healthy_bin_train_new.py" and "subhealthy_bin_new_train.py" contains source codes of program used to train out the four different models.\n

The folder "Data" contains a .rar file that holds all the training data used to train out the current models. The "models" folder contains a .rar file storing the four models currently in used.\n

The files "append_header_to_csv.py", "extract_7k.py", "msdos_to_csv.py" and "pipeline_functions.py" are all files containing helper functions used in the complete flow of the pipeline.\n

The "gui_4.3.pyw" is the file that contains source code of the GUI and the main front-end component.\n

#2. How to Deploy:
1. Download all the files and folders on this repository. Unzip the files in the folder "models" and "Data" in the same location.\n
2. Click on the "gui_4.3.pyw" file and it would launch the GUI automatically. Prediction System would be fully functional from here on.
